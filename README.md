# 🛒 Shopwave – Amazon Clone

Shopwave is a responsive e-commerce web application inspired by Amazon, built using **HTML, CSS, and Vanilla JavaScript**. The project focuses on object-oriented programming, modular JavaScript, and dynamic DOM manipulation to create an interactive shopping experience.

## 🚀 Features

- 📦 Browse products with images, ratings, and prices
- 🛒 Add products to the shopping cart
- 🔢 Update product quantities
- ❌ Remove items from the cart
- 💾 Persistent cart storage using Local Storage
- 🚚 Select different delivery options
- 💰 Automatic order summary and price calculations
- ✅ "Added to Cart" confirmation message
- 📱 Responsive design for different screen sizes

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Object-Oriented Programming (OOP)
- ES6 Modules
